# Climate Change Twitter Analysis

## Project Overview
This project analyzes public opinion on climate change using Twitter data. The goal was to explore sentiment trends, engagement behavior, and discussion patterns through SQL analysis and interactive Power BI dashboards.

## Tools & Technologies
- PostgreSQL -data storage, cleaning & transformation
- Power BI -interactive dashboard & visualisation

## Objectives
- Analyze public sentiment toward climate change
- Identify engagement patterns across tweets
- Create interactive dashboards for decision-making
- Transform raw social media data into actionable insights

## Dataset
Dataset: Climate Change Twitter Dataset (Mendeley Data, 2022)

## Data Cleaning Process
- Checked for duplicates
- Handled null values
- Standardized columns
- Extracted date components for analysis

## SQL Analysis
Created SQL views and queries to analyze:
- Sentiment distribution
- Tweet engagement
- User interaction patterns
- Trend analysis

## Key Insights
- 71.52% of tweets are from climate believers
- 28.67% of all tweets are aggressive
- Politics is the most aggressive topic
- Sentiment peaked in 2016 and declined toward 2019
- Male authors dominate climate discourse at 65%
- Positive and neutral sentiments dominated climate discussions
- Engagement varied significantly across sentiment categories
- Tweet activity increased during major climate-related discussions
